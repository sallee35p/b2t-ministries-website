# Between Two Trees Ministries — Version 1 Website

This repository contains the standalone public website for B2T Ministries.

## Included pages
- Home
- About
- Scripture Guide
- Resources
- The Vision
- Give
- Contact

## Architecture
This site has no Replit dependency and no backend dependency. It can be hosted on a static host such as Cloudflare Pages, Vercel, Netlify, GitHub Pages, or similar.

## Before public launch
1. Replace placeholder image treatments with approved B2T/property photography.
2. Point the Scripture Guide CTA to the final production app URL.
3. Connect a vetted donation platform.
4. Add the official ministry contact email/form.
5. Add finalized privacy policy, terms, and nonprofit disclosures as appropriate.
6. Connect b2tministries.com only after production review.

## Brand direction
Warm, natural, understated, contemporary, Scripture-centered, outdoors-oriented.
